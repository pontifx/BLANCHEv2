Implemented
- Replaced the always-visible Target tab URL with a closed native details/summary disclosure.
- Added compact URL, Params, GET, and POST copy controls shared by the side panel and DevTools console.
- Kept full URLs and generated requests out of data attributes and status messages.
- Added a persistent polite live status region; copy confirmation updates no longer replace the console or discard keyboard focus.
- Disabled parameter copy when the query is empty and disabled request templates for non-HTTP(S) targets.
- Added exact raw query extraction that preserves ordering, duplicate keys, blank/bare parameters, plus signs, percent encoding, and escape casing.
- Added minimal HTTP/1.1 templates:
  GET <path>?<raw-query> HTTP/1.1
  Host: <host>

  POST <path> HTTP/1.1
  Host: <host>
  Content-Type: application/x-www-form-urlencoded
  Content-Length: <UTF-8 byte length>

  <raw-query>
- Fragments and URL credentials are omitted from requests. Default ports normalize; non-default ports and bracketed IPv6 hosts are retained.
- POST is explicitly labeled as a constructed form template derived from the URL query, not an observed POST.
- Raw ASCII control characters are rejected before exact query preservation.
- Added focused unit and real-browser smoke commands and documented the controls.
