Chromium extension Burp Suite extension OSINT workflows

BLANCHE

Browser-side visibility and operator-driven OSINT collection for Burp workflows. BLANCHE captures client-only state, turns it into Burp-readable notes, and keeps search, documents, and seed handoff in one focused console.

Operator Surfaces

Search Workbench

Multi-engine OSINT search launcher with three built-in profiles for public footprint, document exposure, and infrastructure or certificate discovery.

Document Center

Tracks document links and browsed document responses, downloads allowed files, hashes content, extracts URLs, and highlights keywords like token, credential, internal, and admin.

Burp Bridge

Collects Chromium-only page state including storage, IndexedDB, cache, workers, service workers, blob URLs, data URLs, and frame metadata, then posts the export to Burp.

Burp Output

Site Map Annotated synthetic response with BLANCHE notes, a page-state header, and structured JSON.
Organizer Receives the annotated page-state item where Montoya supports handoff.
OSINT Seed Turns browser-visible hosts, forms, assets, iframes, and manifests into a passive public OSINT seed.

Built-In OSINT Profiles

Public Footprint Sweep

  • Google, Bing, Yahoo
  • Login, admin, portal, VPN, SSO, and remote access terms

Documents and Secrets Sweep

  • PDF, Office, spreadsheet, and CSV document types
  • Confidential, internal, password, credential, token, and API key terms

Infrastructure and Certificates

  • Shodan hostname lookups
  • crt.sh wildcard certificate identity lookup
